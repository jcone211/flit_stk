# README 纯文字风格设计

## 目标

让 README 的头部和功能目录更像专业工具文档，减少与项目定位不匹配的装饰性 emoji，同时保留项目图标、徽章和现有功能信息。

## 范围

- 修改 `README.md` 的标题、章节标题、功能表格名称和目录导航。
- 移除 `✨`、`🤖`、`🚀`、`⚡` 等装饰性 emoji。
- 保留顶部项目图标、版本信息、徽章、功能说明、演示图和快速开始内容。
- 不修改扩展代码、功能逻辑或图片资源。

## 视觉规则

- 项目名称使用居中标题：`flit stk · 量化盯盘`。
- 头部继续使用居中项目图标和徽章。
- 章节使用简洁纯文字标题：`核心能力`、`快速开始`、`快速实操`、`详细文档`。
- 功能名称使用专业短标签：`AI Agent`、`多渠道实时行情`、`多条件提醒`等。
- 导航链接的锚点同步更新到新的章节标题。
- 痛点描述保留现有精简文案，不新增额外解释。

## 验收标准

- README 中不再出现上述装饰性 emoji。
- 所有目录链接与章节标题一致。
- 功能表格中的现有功能和说明完整保留。
- 图片路径、JSON 预置数据路径和文档链接不变。
- `git diff --check` 通过。
