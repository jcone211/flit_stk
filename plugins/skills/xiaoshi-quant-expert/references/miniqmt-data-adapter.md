# MiniQMT 本地行情数据兼容规范 / MiniQMT Data Adapter Contract

## 1. 非商业授权限制
- 本地 MiniQMT 兼容模块包含了对第三方开源项目 OSkhQuant 的数据解析器（`miniQMT_data_parser.py`）的接口适配。
- 依据 OSkhQuant 原作者的开源许可协议，本适配能力在小石平台中仅支持**永久免费、无广告、非商业的本地自用研究**。
- 环境变量 `XIAOSHI_OSKH_NONCOMMERCIAL_ENABLED` 作为总控开关。若由于平台合规性升级或加入商业性内容，可通过简单地移除 `third_party/oskhquant/` 文件夹及本适配代码，将系统无缝恢复至纯粹的小石自研数据路径。

## 2. 依赖前提
- 操作系统必须为 Windows（xtquant/MiniQMT 官方客户端仅支持 Windows 平台）。
- 本机已安装迅投 MiniQMT 客户端，并在客户端中正常完成历史数据下载。
- 本地 Python 环境已安装 `xtquant` 库依赖。
- 未安装或未启用本适配器时，系统将发出清晰的依赖缺失报错，不得假造行情或生成静默模拟数据。

## 3. 行情数据映射与隔离规范
- **代码映射**: 小石标准代码形式（如 `600519`）会自动映射到 xtquant 能够识别的交易所后缀格式（如 `600519.SH`）。
- **周期映射**: 小石周期（`daily`, `1min`, `5min`, `15min`, `30min`）映射到 xtquant 对应周期；平台不再提供 60 分钟线。
- **来源隔离**:
  - 从 MiniQMT 适配器转换出来的所有 `Bar` 实例的 `source` 字段必须显式固定为 `DataSource.MINIQMT`。
  - 在同一回测任务内，数据源必须保持绝对冻结和统一，绝对不允许中途动态切换或者把小石主站行情与本地 MiniQMT 缓存数据静默混合。
- **只读权限**: 该模块仅用于策略历史回测及模拟信号观察，**第一阶段严禁通过 MiniQMT 进行实盘下单**。所有实盘下单逻辑必须进行物理隔离，在未获得用户明确单独授权前不得引入。
