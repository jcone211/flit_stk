# 策略、因子与回测实验室

## 因子规格

每个因子先冻结名称、经济假设、输入字段、公式、方向、窗口、滞后、频率、去极值/标准化、行业与市值中性化、缺失值、可交易时点及适用市场。只有目录中存在且在当时可用的字段才能成为输入。

## 策略研究类型

根据假设选择新闻/事件驱动、技术/趋势、均值回归、基本面/价值、多因子选股、统计套利、机器学习或组合与风险覆盖。它们是研究方法，不是八个现成策略；目录中的候选、基准、未通过迭代和生产策略必须按在线状态分别呈现。

## 工作流

1. 用 `get_data_catalog` 读取 quant-data。先读 `derived_factors.definitions` 的全部定义，再按 ID 合并 `items` 中已发布快照；定义存在但快照缺失时保留定义并报告 `snapshot_status`，不得把缺项解释为 0。读取 `strategy_research` 时保留证据版本、回溯标记、成本情景、门禁、早期回看和动态自然前向进度；回溯样本不是独立样本外。
2. 选择一种最小可验证的研究类型，冻结假设、股票池、样本期、基准、调仓、成本和否决条件，不在看到结果后换方向或扫描邻近参数。
3. 用 `prepare_local_research` 生成研究清单，使用 `xiaoshi-data` 下载并验签数据。
4. 运行 `validate-factor` 检查字段、类型、有限值、重复键、覆盖、未来泄露和因子方向。
5. 设定撮合、停牌/涨跌停、T+1、费用、滑点、容量和风险约束；信号、组合构建、执行假设和风险门禁保持可拆分。
6. 运行 `backtest`，使用时间滚动、purge/embargo 或独立样本外区间验证。
7. 报告 IC/RankIC、分层收益、换手、成本前后收益、最大回撤、稳定性、容量与失败区间；保存数据清单、配置、代码版本、成交和报告，策略不得只展示最佳参数。

## 示例请求

- “列出当前通过输入门禁的因子快照，说明每项 as-of、样本、方法和限制，再选择一个做样本外验证。”
- “把这个事件驱动假设冻结成可复现规格，按首次可用时间做事件研究，并报告异常收益、MFE/MAE、成本和同期反例。”
- “比较两个策略候选时使用相同股票池、样本、基准和费用，分别报告样本外表现、回撤、换手、容量和未通过门禁。”

事件和人物可作为可选增强层，但重要度或未来概率不能直接映射为仓位。未经独立验证的策略与因子只能标记为研究结果，不得声称可生产交易。
